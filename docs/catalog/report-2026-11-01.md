Tool fixes found by this batch (separate commits): containers run in the work dir (Orca CLI writes
`00000.log` to cwd; every export aborted); seam-chained `bed_exclude_area` lists decomposed into
rectangles (Kobra 3 frame, Kobra 3 Max / Qidi X-Plus 4 strips: the bounding box was the whole bed);
an array holding one comma string is a point list (Qidi Q2 / X-Max 4 exclusions were dropped);
multi-extruder beds pack into the area every extruder reaches (H2D/H2D Pro 25..325, X2D 20.5..256);
the probe build item is placed from the draft's geometry after `--arrange 1` (Orca's arrange put the
Kobra 3 cube off the bed); deterministic `plate_outline` tracing, and a trace that does not cover the
printable area is dropped; report reasons skip headless-X noise.

## To investigate

**Purge in firmware macros (`printer_catalog annotate`, after the batch).** These start G-codes call a
firmware macro (`START_PRINT` / `PRINT_START`) that does the purge on the printer, so the probe
G-code shows none and `purge_detect` found no lines. `annotate` (the same rule now runs in
`qualify`) raised their `edge_margin_mm` to 5 mm and added a `source.notes` entry; 37 catalog
profiles call macros, 16 of them also purge visibly and were left alone, 21 changed:
creality_ender_3_v3, creality_ender_3_v3_plus, creality_ender_3_v4, creality_k1, creality_k1_cfs_c,
creality_k1_max, creality_k1_max_cfs_c, creality_k1_se, creality_k1_se_cfs_c, creality_k1c,
creality_k1c_cfs_c, sovol_sv06_ace, sovol_sv06_plus_ace, sovol_sv07_plus, voron_2_4_250,
voron_2_4_300, voron_2_4_350, voron_switchwire_250, voron_trident_250, voron_trident_300,
voron_trident_350. Where each macro actually draws its line needs the printers' own firmware
configs; 5 mm is a guess.

**Low-density qualified plates.** Qualified, but the 20×20 mm probe plate holds far fewer cubes than
the bed suggests (a 220² bed fits ~64): anycubic_kobra (220², 36 cubes, 4 purge lines),
anycubic_kobra_2_neo (220², 47, 1), anycubic_i3_mega_s (210², 51, 4), anycubic_4max_pro_2
(270×210, 48, 1). Not explained yet; first check the detected purge lines (and their clearance
band) against the start G-code before trusting these plates.
