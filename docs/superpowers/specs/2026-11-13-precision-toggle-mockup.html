Переключатель «Расчёт поддержек»

Тот же сегментный контрол, что у «Раскладки», сразу под ней. По умолчанию — «Точно» (как сейчас). Подсказка под контролом меняется с выбором.

  • Точно — нынешний откалиброванный векторный расчёт (--precision precise).
  • Быстро — объединение поддержек на растре (--precision fast): на треть быстрее, на столе иногда на одну модель меньше.
  • Режим сохраняется в параметрах задачи: открытая по ссылке задача показывает его в форме только для чтения, «Упаковать заново» его сохраняет.
  • В строке результата рядом с «рассчитано на …» добавляется «быстрый расчёт», только если выбран «Быстро».
