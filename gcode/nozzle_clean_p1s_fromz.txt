; Nozzle-clean layer change G-code for Bambu P1S / P1P / X1 - HEIGHT-ZONE variant:
; wipe every 2nd layer at/above z 6.6 mm, nothing below. This is exactly what
; `nozzle_clean_inject --nozzle-clean from-z=6.6,every=2` produces; on the Goat 3
; project (43 layers, white-on-red section at z 6.6-8.6) it gives 5 wipes at
; z 6.8/7.2/7.6/8.0/8.4, ~+13 s. The first white layer needs no extra wipe - the
; red->white toolchange there already runs the machine's own full wipe sequence.
;
; Cadence twin of nozzle_clean_p1s.txt (same wipe body - the firmware's exact Y265
; toolchange wipe path, field-corrected 2026-09-02); only the conditions differ.
; Knobs:
;   % 2             - wipe stride (every 2nd layer)
;   layer_z >= 6.59 - zone start (6.6 - 0.01 float epsilon)
;
; Slice-verified on the real Goat 3 P1S project via BambuStudio CLI.

; layer num/total_layer_count: {layer_num+1}/[total_layer_count]
{if layer_num > 0}
{if (layer_num + 1) % 2 == 0}
{if layer_z >= 6.59}
;### START: NOZZLE CLEAN (P1S) ###
M400 ; finish all queued moves
G1 Z{max_layer_z + 3.0} F1200 ; drop bed 3mm below the tallest printed part (firmware toolchange idiom)
M83 ; relative extrusion
G1 E-2.0 F1800 ; retract before travel
G1 X70 F21000 ; to the chute approach column (firmware toolchange path)
G1 Y245
G1 Y265 F3000 ; over the back edge, into the wiper zone
G1 X90 F3000 ; scrape onto the wiper tab
G1 Y255 F4000
G1 X105 F5000
G1 Y265 F5000
G1 X70 F10000 ; wipe passes across the tab
G1 X100 F5000
G1 X70 F10000
G1 X100 F5000
G1 X70 F10000
G1 X80 F15000 ; flick the rocker to shed debris
G1 X60
G1 X80
G1 X60
G1 X80
G1 X100 F5000
G1 X165 F15000 ; final wipe on the right-side scraper
G1 E2.0 F1800 ; prime nozzle back to pressure
G1 Y256 ; move Y aside, prevent collision (firmware trailer)
G1 Z{layer_z} F1200 ; return bed to the new layer height
;### END: NOZZLE CLEAN (P1S) ###
{endif}
{endif}
{endif}
; update layer progress
M73 L{layer_num+1}
M991 S0 P{layer_num} ;notify layer change
