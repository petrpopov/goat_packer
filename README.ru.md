# Goat packer

*[English version](README.md)*

Упаковщик 2D-раскладок для FDM-печати. Работает не с габаритным прямоугольником модели, а с
**реальным силуэтом её плоского дна** — сохраняет внешний контур и внутренние отверстия,
предрастеризует повёрнутые копии, расширяет каждую на половину заданного зазора и проверяет
столкновения бит-параллельно. Главная цель — количество объектов на столе; компактность только
разрешает ничьи.

Задача нерегулярного раскроя NP-трудна, поэтому поиск эвристический: больший бюджет рестартов может
улучшить результат, а фиксированный seed делает конкретную команду воспроизводимой.

## Сборка и тесты

```bash
cargo build --release
cargo test --release --all
python3 tests/test_build_3mf.py -v
```

## Упаковка плиты

`colored_3mf_packer` слайсит исходный проект один раз, чтобы найти реальное положение башни
очистки, раскладывает копии объекта вокруг неё и всех фиксированных запретных зон, после чего
собирает новый 3MF:

```bash
./target/release/colored_3mf_packer \
  --source path/to/source.3mf \
  --profile profiles/p1s.json \
  --output packed.3mf \
  --work-dir work \
  --clearance 0.7 --attempts 16000 --seed 20270831
```

Рядом с результатом пишется `packed.verification.json` с количеством объектов, границами башни на
пробном и финальном слайсе и признаком того, потребовалась ли перекладка.

## Планирование суток печати

`daily_scheduler` берёт готовые упакованные плиты (по одной на принтер), замеряет реальное время
слайса для каждого размера партии и оптимизирует 24-часовое расписание:

```bash
./target/release/daily_scheduler \
  --printer "profile=profiles/p1s.json,source=packed_p1s.3mf" \
  --printer "profile=profiles/snapmaker_u1.json,source=packed_u1.3mf,prep-min=11" \
  --turnaround-min 10 \
  --output-dir schedule_output
```
